# R-Pi AI Calling Maha Maharaja

An offline-first AI-powered calling assistant built on Raspberry Pi that can answer phone calls, transcribe speech, generate intelligent responses, and speak back to the caller in real time.

## Features

- 📞 Automatic call handling
- 🎙️ Real-time Speech-to-Text (Whisper)
- 🧠 LLM-powered response generation
- 🔊 Natural Text-to-Speech (Piper)
- 🎧 Bluetooth HFP audio routing
- 🍓 Optimized for Raspberry Pi
- 🔒 Privacy-first local processing

## Tech Stack

- Raspberry Pi
- Python
- Whisper
- Piper TTS
- PipeWire
- BlueZ
- WebRTC VAD
