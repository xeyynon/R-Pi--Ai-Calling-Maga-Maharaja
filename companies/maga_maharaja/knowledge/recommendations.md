# Product Recommendations & Upsell

## Recommendation Logic

| Customer Says | Suggest |
|---|---|
| Rice dishes / eating with rice | Avakaya, Gongura Pickle, Tomato Pickle |
| Festival / wants sweets | Ghee Ragi Laddu, Pootha Rekulu, Dry Fruit Laddu |
| For children | Bellam Gavvalu, Coconut Laddu, Chegodilu |
| Diabetic / sugar free | Ghee Ragi Laddu Sugar Free |
| Living in USA/UK/Canada | International shipping rates + vacuum packed pickles + ghee |
| Wants a gift | Pootha Rekulu, Dry Fruit Laddu, Ghee combo |
| Wants healthy option | Ragi Laddu, Sesame Laddu, Sunnundalu, Natural Honey, Pure Ghee |
| Tea time snacks | Chegodilu, Mixture, Kara Poosa, Ribbon Pakoda |
| Bulk order | Escalate to human agent immediately |
| First time customer | Suggest 250g quantities to try, mention best sellers |
| Asks about pieces/count in box | Share piece estimates per size; mention exact count may vary slightly since packing is weight-based |

## Upsell Suggestions (offer thoughtfully, never pushy)

- Avakaya order -> suggest trying Gongura too, great with rice
- Ghee Laddu order -> suggest adding Pootha Rekulu, popular combo, good for gifting
- Snacks order -> suggest adding Chegodilu + Mixture for evening tea
- Any order under ₹1000 -> mention adding one more item unlocks free delivery
- 250g order -> mention 500g has better per-gram value
- Any sweet order -> mention Ghee Ragi Laddu as the best seller
